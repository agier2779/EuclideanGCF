
# C Linked List GCF Calculator

This project is a command-line utility designed to calculate the Greatest Common Factor (GCF) for a dynamic set of integers provided by the user. It was developed in C to demonstrate a practical application of manual memory management and custom data structures, specifically using a singly linked list to store and traverse input data. To determine the GCF, I implemented the Euclidean algorithm, which efficiently reduces pairs of numbers until the greatest common divisor is found. The development process involved creating functions for dynamic node allocation, list insertion, and a "used" flag system to ensure each number in the list is processed correctly. During the testing phase, I had to fix a bug where uninitialized variables for the "first" and "second" integers led to unpredictable results, which I resolved by properly resetting them within the calculation loops.
